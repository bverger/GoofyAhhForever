The .ogg files in this folder ship with the addon and are free licensed. See
CREDITS.md for the author and licence of each one.

The meme clips are not here, because they are not mine to hand out. Adding them
takes a minute:

1. Download the ones you want. .mp3 and .ogg both work.

2. Drop them in this folder.

3. Name them after any entry the addon is looking for. Type /goofy list in game
   for the whole list. The ones waiting for a file:

       vineboom.mp3      bruh.mp3         metalpipe.mp3
       emotionaldamage.mp3   augh.mp3     bonk.mp3
       huhcat.mp3        violin.mp3       windowserror.mp3
       fart.mp3          goofylaugh.mp3   sneezeboom.mp3

4. /reload, and run /goofy rescan so the addon stops skipping the names it had
   already written off.
